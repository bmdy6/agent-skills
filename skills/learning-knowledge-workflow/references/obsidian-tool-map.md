# Obsidian 与当前知识库

## 工具层级

| 工具 | 作用 | 边界 |
|---|---|---|
| knowledge-mcp | Markdown / Git 真源 + 受保护读写入口 | 唯一内容真源 |
| Obsidian | 本地阅读、编辑、双链、Graph、Canvas、Bases | 工具层 |
| Workbench | 手机 / 网页日常阅读 | 精选派生层 |
| Web Clipper | 快速采集外部素材 | 只能作为素材入口 |

## 正确链路

外部文章 / GitHub / 视频 / 课程
→ 先判断有没有长期价值
→ 需要证据留存时进入 personal/调研/
→ 真正学会或形成稳定判断后融入顶层主题主文章
→ 值得半年后重读才加 阅读/沉淀
→ Workbench 下一次快照自动出现

## 可以借用的 Obsidian 能力

- Markdown / wikilinks：本地阅读与关联。
- Graph / Canvas / Bases：做导航和视图。
- Web Clipper：快速捕获外部素材。
- CLI / Agent 技能：做格式操作。

这些能力都不能覆盖 knowledge-mcp 的内容模型和写入安全。

## 禁止事项

- 不恢复旧生成阅读层。
- 不把 Canvas / Bases 当第二正文。
- 不为每个概念新建卡片制造重复真源。
- 不让 Clipper 把未消化网页直接升级成长期知识。
- 不直接修改 Workbench WebDAV 快照里的正文。
